# Ujjwal Gupta — Portfolio

Personal portfolio website built on a React + TypeScript + MUI template.

## Stack
- React 18 + TypeScript
- Material UI (MUI v5)
- SCSS
- React Vertical Timeline Component
- FontAwesome Icons

## Sections
- **Hero** — Intro, photo, social links
- **Skills & Expertise** — Languages, Frameworks, Databases & Tools
- **Education & Milestones** — NIT Jalandhar, Achievements timeline
- **Projects** — BioShield-UPI, Wanderly, Dijkstra Visualizer
- **Competitive Programming** — LeetCode, Codeforces, CodeChef, CodingNinjas, GfG
- **Contact** — Email form + social links

## Getting Started

```bash
npm install --legacy-peer-deps
npm start
```

## Build

```bash
npm run build
```

## Deploy (Netlify / Vercel)
Upload the `build/` folder as a static site.
